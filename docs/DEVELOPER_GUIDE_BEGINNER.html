3. 개발 환경 준비

cd "D:\Codex Project\Network\backbone_state_tracker"
python -m pip install -r requirements.txt

4. 점검 명령 추가 방법

명령은 config/commands.yaml에 추가합니다.

- id: ospf_peer
  command: display ospf peer
  description: OSPF neighbor state. Full state should remain stable.
  category: routing
  allow_failure: true
  timeout: 45
필드설명
id명령 결과 파일명과 비교 기준으로 쓰는 고유 ID
command장비에서 실행할 읽기 전용 명령
category비교 등급 분류에 사용하는 범주
allow_failure장비에서 지원하지 않아도 전체 수집을 계속할지 여부
timeout명령별 대기 시간

5. 비교 등급 조정

  • VOLATILE_PATTERNS: 시간, uptime 등 비교 제외 줄
  • CRITICAL_PATTERNS: Critical 키워드
  • WARNING_PATTERNS: Warning 키워드
  • classify_change(): 범주와 변경 내용으로 등급 결정
