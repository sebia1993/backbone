## 2. v0.7.6 변경내역

### 추가 및 변경

- GUI 작업 로그, 스냅샷 메타데이터, HTML/XLSX/JSON 비교 리포트에 민감 문자열 마스킹을 적용했습니다.
- `password`, `secret`, `token`, `authorization`, URL credential, Cisco typed secret, SNMP community 문자열을 `***`로 표시합니다.
- 명령별 `raw/*.txt` 원본 출력 파일은 운영 증거 보존을 위해 그대로 유지합니다.
- 연결 실패 오류와 명령 실패 예외 메시지도 같은 마스킹 규칙을 사용합니다.
- `tests/test_redaction.py`와 리포트 마스킹 회귀 테스트를 추가했습니다.

### 운영 영향

- 외부 공유용 HTML/XLSX/JSON 리포트에서 명백한 비밀값 노출 가능성이 줄었습니다.
- 장비명, IP, 인터페이스, VLAN, 라우팅 값처럼 변경 추적에 필요한 운영 식별자는 자동 마스킹하지 않습니다.
- 원본 명령 출력 파일은 그대로 남으므로 대외 제출 전에는 raw 파일 공유 범위를 별도로 확인해야 합니다.

## 3. v0.7.5 변경내역

### 추가 및 변경

- `대시보드`와 `비교 결과` 화면에 `샘플 검증 생성` 버튼을 추가했습니다.
- 실제 장비 접속 없이 `[샘플] 작업 전`, `[샘플] 백본3 OFF 중`, `[샘플] 복구 후` 스냅샷을 생성합니다.
- 작업 전 대비 백본3 OFF, 작업 전 대비 복구 후, 백본3 OFF 대비 복구 후 비교 리포트를 생성합니다.
- 백본3 접속 불가 Critical 항목과 복구 Info 항목을 샘플 비교군에 포함합니다.
- 샘플 생성 회귀 테스트를 추가했습니다.

### 운영 영향

- 사내 반입 전 또는 교육 중 실제 장비 없이 비교 화면과 리포트 생성을 검증할 수 있습니다.
- 샘플 결과는 `[샘플]` 라벨로 실제 작업 결과와 구분됩니다.
- SSH 접속, 계정 입력, 실제 장비 명령 실행은 수행하지 않습니다.

## 4. v0.7.4 변경내역

### 추가 및 변경

- GUI `비교 결과` 화면의 `최근 변경 상세` 목록에 `판단` 컬럼을 추가했습니다.
- 기준 라인과 비교 라인을 `기준 → 비교` 형태의 단일 `라인` 값으로 표시합니다.
- 변경 행을 선택하면 핵심 판단, 변경 전/후 값, 원본 파일 위치, 등급별 운영 메모를 먼저 표시합니다.
- 긴급/주의/정보 등급별 행 색상을 적용해 변경 항목을 더 빠르게 스캔할 수 있게 했습니다.
- GUI 비교 상세 포맷 단위 테스트를 추가했습니다.

### 운영 영향

- 운영자는 어떤 장비, 어떤 명령, 어떤 라인, 어떤 값이 바뀌었는지 한 행에서 더 빠르게 확인할 수 있습니다.
- 선택 상세 패널에서 원본 파일 위치와 등급별 확인 방향을 함께 볼 수 있습니다.
- 장비 수집 명령, 스냅샷 형식, HTML/XLSX/JSON 리포트 형식은 변경하지 않았습니다.

## 5. v0.7.3 변경내역

### 추가 및 변경

- 같은 단계 스냅샷을 같은 초에 두 번 이상 저장해도 기존 폴더를 덮어쓰지 않도록 했습니다.
- 최초 스냅샷은 기존 timestamp 폴더명을 유지하고, 중복이 있을 때만 `_001`, `_002` 순번을 붙입니다.
- 스냅샷 메타데이터, 명령 출력, 비교 리포트가 서로 다른 폴더에 분리되어 보관됩니다.
- 같은 라벨과 같은 초의 반복 저장 회귀 테스트를 추가했습니다.

### 운영 영향

- 작업자가 같은 수집 버튼을 빠르게 두 번 눌러도 이전 수집 결과가 섞이거나 사라질 위험이 줄었습니다.
- 기존 스냅샷 폴더 구조와 리포트 파일 형식은 유지됩니다.
- 실제 장비 수집 명령과 비교 엔진은 변경하지 않았습니다.

## 6. v0.7.2 변경내역

### 추가 및 변경

- 장비별 접속 상태를 `device_connectivity` 내부 결과로 스냅샷에 저장합니다.
- 장비가 접속 불가이면 비교 결과에 해당 장비를 단일 Critical 항목으로 표시합니다.
- 접속 불가 장비의 일반 점검 명령 누락은 여러 건으로 표시하지 않고 접속 실패 항목으로 대표합니다.
- 기존 스냅샷도 정상 명령 결과 또는 예전 접속 실패 결과를 기준으로 접속 상태를 보정해 비교합니다.
- 장비 접속 복구는 Info 항목으로 표시합니다.

### 운영 영향

- 백본 3/4호기 중 한 대가 다운되어도 비교군에서 빠지지 않습니다.
- 운영자는 `device_connectivity` 항목만 보면 장비 접속 실패 또는 복구 여부를 빠르게 확인할 수 있습니다.
- 실제 장비 수집 명령과 사용자 설정 파일 형식은 변경하지 않았습니다.

## 7. v0.7.1 변경내역

### 추가 및 변경

- HTML 비교 리포트의 변경 상세 테이블을 `유형`, `라인`, `변경 내용` 3열 구조로 재설계했습니다.

- 긴 명령 출력은 변경 상세 영역의 가로 스크롤로 확인하도록 조정했습니다.
- 원본 unified diff 접힘 영역은 그대로 유지했습니다.

### 운영 영향

- HTML 리포트에서 어느 부분이 바뀌었는지 더 빠르게 읽을 수 있습니다.
- GUI 비교 화면, XLSX `diff_detail` 시트, JSON manifest, 장비 수집 명령은 변경하지 않았습니다.

## 18. 반입 전 확인사항

- ZIP 파일명에 의도한 버전이 포함되어 있는지 확인합니다.
- `docs/` 폴더에 사용자 가이드, 개발자 가이드, 버전 변경내역 문서가 Markdown/HTML 모두 있는지 확인합니다.
- 소스 ZIP에 `.git`, `outputs/`, `dist/`, `config/devices.yaml`이 포함되지 않았는지 확인합니다.
- Windows EXE ZIP에 `BackboneStateTracker.exe`가 포함되어 있는지 확인합니다.
- 장비 IP, 계정, 원본 출력 등 내부 정보가 배포 파일에 포함되지 않았는지 확인합니다.
