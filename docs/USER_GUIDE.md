# Backbone State Tracker 사용자 가이드

문서 버전: v0.7.2
작성일: 2026-06-11
대상: 백본 3/4호기 상태 점검 및 휴전 작업 검증 담당자

## 1. 핵심 운영 포인트

- 먼저 `작업 전` 상태를 수집합니다. 이후 `백본3 OFF 중`, `복구 후`, `사용자 지정` 단계는 최신 `작업 전` 스냅샷과 자동 비교됩니다.
- 장비 변경 명령은 실행하지 않습니다. `config/commands.yaml`에 정의된 읽기 전용 점검 명령만 실행합니다.
- 암호는 저장하지 않습니다. 프로그램 종료 후 다시 입력해야 합니다.
- 비교 리포트는 HTML, XLSX, JSON으로 생성되며 `outputs/snapshots/` 아래에 저장됩니다.
- 긴급 또는 주의 변경점이 나오면 해당 명령의 원본 출력 파일과 HTML 리포트를 함께 확인합니다.
- 비교 결과에서 변경된 라인의 `변경 전`과 `변경 후` 값을 직접 확인합니다.
- HTML 리포트는 변경 내용을 `기존값 → 신규값` 형태로 한 줄에 표시합니다.
- 장비 1대가 접속 불가이면 해당 장비는 `device_connectivity` 긴급 항목으로 비교 결과에 포함됩니다.
- 대시보드의 `작업 진행 마법사`를 따라가면 다음 단계 버튼으로 작업 흐름을 이어갈 수 있습니다.

## 2. 프로그램 동작 방식

1. `대시보드`의 작업 진행 마법사에서 현재 단계와 다음 액션을 확인합니다.
2. 필요 시 `장비 설정` 화면에서 백본 3/4호기 IP, 포트, 장비 타입, 접속 계정을 입력합니다.
3. 프로그램이 장비에 SSH로 접속해 읽기 전용 명령을 실행합니다.
4. 장비별 접속 상태와 명령 출력이 시간별 스냅샷 폴더에 저장됩니다.
5. 작업 전이 아닌 단계는 최신 `작업 전` 스냅샷과 자동 비교됩니다.
6. `비교 결과` 화면 또는 `최근 리포트` 버튼으로 변경점을 확인합니다.

## 3. 화면 구성

### 대시보드

- 긴급, 주의, 정보, 변경없음 건수를 요약합니다.
- 최근 스냅샷, 최근 리포트, 현재 비교 상태를 보여줍니다.
- `작업 진행 마법사`가 장비 설정 확인, 작업 전 수집, 백본3 OFF 중 수집, OFF 중 변경 확인, 복구 후 수집, 최종 확인 순서로 안내합니다.
- `다음 단계` 버튼은 완료 결과를 확인한 뒤에만 다음 작업으로 넘어가도록 설계되어 있습니다.

### 상태 수집

- `작업 전`, `백본3 OFF 중`, `복구 후`, `사용자 지정` 단계 중 하나를 선택합니다.
- 사용자 지정 단계는 별도 단계명이 필요할 때 사용합니다.

### 비교 결과

- 기준 스냅샷과 비교 스냅샷을 직접 선택해 다시 비교할 수 있습니다.
- 자동 비교가 누락되었거나 특정 시점끼리 재확인이 필요할 때 사용합니다.
- `최근 변경 상세` 목록에서 변경된 행을 선택하면 장비, 명령, 기준 라인, 비교 라인, 변경 전/후 값을 확인할 수 있습니다.
- 접속 불가 장비는 일반 명령 누락을 여러 건으로 나열하지 않고 `device_connectivity` 긴급 항목 한 줄로 표시합니다.

### 장비 설정

- 백본 3/4호기 접속 정보와 SSH 계정을 입력합니다.
- `장비 목록 저장`은 장비 정보만 저장합니다. 암호는 저장하지 않습니다.

### 작업 로그

- 수집 시작, 저장 위치, 비교 완료, 오류 메시지를 확인합니다.

## 4. 권장 작업 순서

1. `장비 설정`에서 백본 3/4호기 정보와 접속 계정을 확인합니다.
2. 대시보드의 `작업 전 수집 시작` 버튼으로 기준 스냅샷을 생성합니다.
3. 백본 3호기 OFF, 백본 4호기 ON 상태에서 `백본3 OFF 중 수집 시작`을 실행합니다.
4. `OFF 중 변경 상세 확인`으로 자동 비교 결과의 긴급/주의 항목을 확인합니다.
5. 복구 후 백본 3/4호기 ON 상태에서 `복구 후 수집 시작`을 실행합니다.
6. `최종 변경 상세 확인`과 `최종 리포트 열기`로 작업 결과를 보관합니다.

## 5. 리포트 확인

- `최근 리포트`: 현재 실행 세션에서 마지막으로 생성된 HTML 리포트를 엽니다.
- `결과 폴더`: 전체 스냅샷과 리포트가 저장된 폴더를 엽니다.
- XLSX 리포트는 변경점 공유나 회의 자료 정리에 사용합니다.
- HTML 리포트는 명령별 변경 상세 테이블과 원본 unified diff를 함께 제공합니다.
- HTML 변경 상세는 `유형`, `라인`, `변경 내용` 구조입니다. 변경 행은 `기존값 → 신규값`, 추가 행은 `추가: 신규값`, 삭제 행은 `삭제: 기존값`으로 표시됩니다.
- 장비 접속 실패는 `reachable → unreachable: timeout`처럼 접속 상태 변경으로 표시됩니다.
- 명령 출력이 긴 경우 HTML 리포트의 변경 상세 영역에서 가로 스크롤로 확인합니다.
- XLSX 리포트의 `diff_detail` 시트는 장비, 명령, 변경 유형, 기준 라인, 비교 라인, 변경 전/후 값을 행 단위로 제공합니다.

## 6. 주의 사항

- 운영 장비 대상이므로 작업 전 승인된 점검 시간과 접속 권한을 확인합니다.
- 사내 반입용 ZIP에는 로컬 `config/devices.yaml`과 `outputs/`가 포함되지 않도록 유지합니다.
- 실제 장비 설정 변경, 재부팅, 포트 shutdown 같은 명령은 이 도구에 추가하지 않습니다.
