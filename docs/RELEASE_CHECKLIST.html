Backbone State Tracker 릴리스 반입 체크리스트

문서 버전: v0.8.22
작성일: 2026-06-12
대상: 사외 개발 ZIP을 사내 환경으로 반입해 검증하는 운영자와 인수자

1. 수령 파일

backbone_state_tracker_v0.8.22_YYYYMMDD_source.zip
backbone_state_tracker_v0.8.22_YYYYMMDD_source.zip.sha256.txt
backbone_state_tracker_v0.8.22_YYYYMMDD_windows_exe.zip
backbone_state_tracker_v0.8.22_YYYYMMDD_windows_exe.zip.sha256.txt
backbone_state_tracker_v0.8.22_YYYYMMDD_release_manifest.txt
backbone_state_tracker_v0.8.22_YYYYMMDD_verify_release_package.ps1

2. ZIP 내부 필수 확인

  • PACKAGE_INFO.txt, README.md, CHANGELOG.md
  • config/commands.yaml, config/devices.example.yaml
  • 사용자/명령어/개발자/버전/체크리스트 문서의 MD와 HTML
  • docs/images/settings-collection.png
  • docs/images/compare-results.png
  • docs/images/work-log.png
  • Windows EXE ZIP인 경우 BackboneStateTracker.exe, RUN_FIRST.txt

3. 포함되면 안 되는 항목

  • .git/, outputs/, raw/, dist/, build/
  • config/devices.yaml, __pycache__/, .pyc, .spec

4. 해시와 manifest 검증

Get-FileHash -Algorithm SHA256 .\backbone_state_tracker_v0.8.22_YYYYMMDD_windows_exe.zip
python .\tools\verify_release_package.py .\dist\backbone_state_tracker_v0.8.22_YYYYMMDD_windows_exe.zip --require-manifest
powershell -ExecutionPolicy Bypass -File .\backbone_state_tracker_v0.8.22_YYYYMMDD_verify_release_package.ps1 -Package .\backbone_state_tracker_v0.8.22_YYYYMMDD_windows_exe.zip -RequireManifest

5. 실행 확인

  • EXE ZIP을 별도 폴더에 해제하고 RUN_FIRST.txt를 확인합니다.
  • BackboneStateTracker.exe를 실행합니다.
  • 첫 화면이 장비 설정이고 좌측 메뉴가 장비 설정, 비교 결과, 작업 로그 순서인지 확인합니다.
  • 샘플 검증 생성으로 실제 장비 접속 없이 리포트 생성이 되는지 확인합니다.
