1. 최신 버전

v0.8.57 - 2026-06-15

  • 실제 장비 없이 테스트할 수 있는 모의 SSH/Telnet 서버와 합성 프로파일을 포함했습니다.
  • 회사 현장 진단용 자체 점검 리포트가 원본 로그 없이 단계별 상태와 오류 코드만 남기도록 보강했습니다.
  • 진단 산출물에서 장비명, 호스트명, IP, secret 계열 값을 자동 마스킹하도록 적용했습니다.
  • GUI 도움말, 공유 리포트 ZIP, 릴리스 패키지에 진단 모드 가이드와 오류 코드 카탈로그를 포함했습니다.
  • Windows EXE 빌드 단계에서 smoke, 진단, 모의 Telnet, 모의 SSH 자체 점검을 모두 실행하도록 검증 범위를 넓혔습니다.

v0.8.56 - 2026-06-15

  • UI 현대화 분석 보강으로 현대화 전 문제 원인과 설계 대응 요약을 초급 개발자 가이드에 추가했습니다.
  • 색상, 여백/테두리, 버튼 우선순위, 테이블/비교 결과, 로그, 메뉴 배치 관점에서 기존 UI가 구식으로 보이던 이유를 문서화했습니다.
  • v0.8.52~v0.8.55에서 적용한 AirWave 계열 운영 콘솔 방향, 장비 설정 중심 흐름, 상태 색상 토큰, 비교 결과 맥락 패널, 작업 로그 표면의 설계 대응을 정리했습니다.
  • 수집, SSH, 비교 데이터, 리포트 데이터, 등급 분류 동작은 변경하지 않았습니다.

v0.8.55 - 2026-06-15

  • UI 현대화 마감 단계로 사용자 가이드 화면 캡처, 개발자 디자인 기준, 릴리스 반입 체크리스트를 v0.8.55 기준으로 정리했습니다.
  • 초급 개발자 가이드에 PALETTE, SEVERITY_META, SEVERITY_COLORS, SEVERITY_SOFT_COLORS 디자인 토큰과 컴포넌트 사용 기준을 추가했습니다.
  • 릴리스 체크리스트에 실제 반입 시 확인할 좌측 내비게이션, 장비 설정 흐름, 비교 등급 카드, 선택 변경 맥락, 작업 로그 UI 확인 항목을 추가했습니다.
  • 수집, SSH, 비교 데이터, 리포트 데이터, 등급 분류 동작은 변경하지 않았습니다.
