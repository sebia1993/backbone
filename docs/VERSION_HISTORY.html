2. v0.7.3 변경내역

추가 및 변경

  • 같은 단계 스냅샷을 같은 초에 두 번 이상 저장해도 기존 폴더를 덮어쓰지 않도록 했습니다.
  • 최초 스냅샷은 기존 timestamp 폴더명을 유지하고, 중복이 있을 때만 _001, _002 순번을 붙입니다.
  • 스냅샷 메타데이터, 명령 출력, 비교 리포트가 서로 다른 폴더에 분리되어 보관됩니다.
  • 같은 라벨과 같은 초의 반복 저장 회귀 테스트를 추가했습니다.

운영 영향

  • 작업자가 같은 수집 버튼을 빠르게 두 번 눌러도 이전 수집 결과가 섞이거나 사라질 위험이 줄었습니다.
  • 기존 스냅샷 폴더 구조와 리포트 파일 형식은 유지됩니다.
  • 실제 장비 수집 명령과 비교 엔진은 변경하지 않았습니다.

3. v0.7.2 변경내역

추가 및 변경

  • 장비별 접속 상태를 device_connectivity 내부 결과로 스냅샷에 저장합니다.
  • 장비가 접속 불가이면 비교 결과에 해당 장비를 단일 Critical 항목으로 표시합니다.
  • 접속 불가 장비의 일반 점검 명령 누락은 여러 건으로 표시하지 않고 접속 실패 항목으로 대표합니다.
  • 기존 스냅샷도 정상 명령 결과 또는 예전 접속 실패 결과를 기준으로 접속 상태를 보정해 비교합니다.
  • 장비 접속 복구는 Info 항목으로 표시합니다.

운영 영향

  • 백본 3/4호기 중 한 대가 다운되어도 비교군에서 빠지지 않습니다.
  • 운영자는 device_connectivity 항목만 보면 장비 접속 실패 또는 복구 여부를 빠르게 확인할 수 있습니다.
  • 실제 장비 수집 명령과 사용자 설정 파일 형식은 변경하지 않았습니다.

4. v0.7.1 변경내역

추가 및 변경

  • HTML 비교 리포트의 변경 상세 테이블을 유형, 라인, 변경 내용 3열 구조로 재설계했습니다.
  • 변경 행은 기존값 → 신규값 형태로 한 줄에 표시합니다.
  • 추가 행은 추가: 신규값, 삭제 행은 삭제: 기존값으로 표시합니다.
  • 긴 명령 출력은 변경 상세 영역의 가로 스크롤로 확인하도록 조정했습니다.
  • 원본 unified diff 접힘 영역은 그대로 유지했습니다.

운영 영향

  • HTML 리포트에서 어느 부분이 바뀌었는지 더 빠르게 읽을 수 있습니다.
  • GUI 비교 화면, XLSX diff_detail 시트, JSON manifest, 장비 수집 명령은 변경하지 않았습니다.

5. v0.7.0 변경내역

추가 및 변경

  • 대시보드에 작업 진행 마법사를 추가했습니다.
  • 장비 설정 확인, 작업 전 수집, 백본3 OFF 중 수집, OFF 중 변경 확인, 복구 후 수집, 최종 확인 단계 카드를 추가했습니다.
  • 현재 단계에 맞는 단일 다음 단계 버튼을 추가했습니다.
  • OFF 중 변경 상세 확인 전에는 마법사에서 복구 후 수집 단계가 잠기도록 했습니다.
  • 기존 좌측 메뉴, 수동 수집, 수동 비교, 리포트 생성 동작은 유지했습니다.

운영 영향

  • 작업자는 대시보드에서 다음 액션만 따라가면 전체 흐름을 진행할 수 있습니다.
  • 단계 완료 후 자동으로 다음 작업을 실행하지 않고, 결과 확인 후 버튼으로 넘어갑니다.
  • 실제 장비 수집 명령과 비교 엔진은 변경하지 않았습니다.

6. v0.6.0 변경내역

추가 및 변경

  • 스냅샷 비교 결과에 행 단위 변경 상세를 추가했습니다.
  • GUI 비교 결과 화면에 최근 변경 상세 목록과 변경 전/후 상세 패널을 추가했습니다.
  • HTML 리포트에 기준 라인, 비교 라인, 변경 전, 변경 후를 보여주는 상세 테이블을 추가했습니다.
  • XLSX 리포트에 diff_detail 시트를 추가했습니다.
  • JSON manifest에 changed_lines, change_count, change_preview를 추가했습니다.

운영 영향

  • 기존 작업 순서와 수집 명령은 동일합니다.
  • 기존 unified diff는 HTML 리포트에서 접힌 영역으로 계속 확인할 수 있습니다.
  • 운영자는 어떤 장비의 어떤 명령 출력에서 어느 라인이 바뀌었는지 바로 확인할 수 있습니다.

7. v0.5.0 변경내역

추가 및 변경

  • 밝은 운영 콘솔형 GUI로 재설계했습니다.
  • 좌측 메뉴를 추가했습니다: 대시보드, 상태 수집, 비교 결과, 장비 설정, 작업 로그.
  • 상단 상태 바에 현재 상태, 기준 스냅샷, 비교 대상을 표시합니다.
  • 대시보드에 긴급, 주의, 정보, 변경없음 지표 카드를 추가했습니다.
  • 사용자 가이드, 초급 개발자 가이드, 버전 변경내역 문서를 Markdown과 HTML 모두 업데이트했습니다.

유지된 동작

  • 장비 수집 방식은 SSH 기반 읽기 전용 점검 그대로입니다.
  • 작업 전은 자동 비교 기준으로 사용됩니다.
  • 백본3 OFF 중, 복구 후, 사용자 지정 단계는 최신 작업 전 스냅샷과 자동 비교됩니다.
  • HTML, XLSX, JSON 리포트 생성 방식은 유지됩니다.

운영 영향

  • 메뉴 구조가 바뀌었지만 작업 순서는 동일합니다.
  • 기존 스냅샷 폴더와 리포트는 그대로 사용할 수 있습니다.
  • 공식 HPE/Aruba 로고나 고유 브랜드 자산은 포함하지 않았습니다.

11. 반입 전 확인사항

  • ZIP 파일명에 의도한 버전이 포함되어 있는지 확인합니다.
  • docs/ 폴더에 사용자 가이드, 개발자 가이드, 버전 변경내역 문서가 Markdown/HTML 모두 있는지 확인합니다.
  • 소스 ZIP에 .git, outputs/, dist/, config/devices.yaml이 포함되지 않았는지 확인합니다.
  • Windows EXE ZIP에 BackboneStateTracker.exe가 포함되어 있는지 확인합니다.
  • 장비 IP, 계정, 원본 출력 등 내부 정보가 배포 파일에 포함되지 않았는지 확인합니다.
