2. v0.8.11 변경내역

추가 및 변경

  • Python/PowerShell 배포 ZIP 검증기가 ZIP 내부 파일이 backbone_state_tracker/ 루트 아래에 있는지 확인합니다.
  • 절대 경로, Windows 드라이브 경로, 빈 경로 조각, . 또는 .. 이동 경로가 있는 ZIP 엔트리는 Unsafe ZIP entry found 오류로 실패합니다.
  • backbone_state_tracker/ 루트 밖의 파일은 Unexpected ZIP root entry found 오류로 실패합니다.
  • 예상 밖의 최상위 파일, 경로 이동 엔트리, 절대 경로 엔트리에 대한 회귀 테스트를 추가했습니다.

운영 영향

  • 사외에서 만든 ZIP을 사내로 반입할 때 압축 해제 위치 밖으로 파일이 풀리는 구조를 더 빨리 차단할 수 있습니다.
  • 프로그램 실행, 수집, 비교, 리포트 형식은 변경하지 않았습니다.

3. v0.8.10 변경내역

추가 및 변경

  • Python/PowerShell 배포 ZIP 검증기가 .sha256.txt의 SHA256 (<파일명>) 대상 이름이 실제 ZIP 파일명과 일치하는지 확인합니다.
  • release_manifest.txt에서 해당 ZIP의 Package, Size, SHA256 레코드를 찾아 실제 ZIP 크기와 해시가 정확히 맞는지 확인합니다.
  • manifest 다른 위치에 같은 SHA 문자열이 있더라도 해당 패키지 레코드가 틀리면 실패하도록 회귀 테스트를 추가했습니다.

운영 영향

  • 반입 폴더에 여러 ZIP과 manifest가 섞여 있을 때, 이름만 보이는 느슨한 일치가 아니라 해당 패키지 레코드 단위로 무결성을 확인할 수 있습니다.
  • 프로그램 실행, 수집, 비교, 리포트 형식은 변경하지 않았습니다.

27. 버전 확인 방법

Backbone State Tracker v0.8.11

소스 기준으로는 core/version.py를 확인합니다.

28. 배포 ZIP 예시

dist\backbone_state_tracker_v0.8.11_20260612_source.zip
dist\backbone_state_tracker_v0.8.11_20260612_source.zip.sha256.txt
dist\backbone_state_tracker_v0.8.11_20260612_windows_exe.zip
dist\backbone_state_tracker_v0.8.11_20260612_windows_exe.zip.sha256.txt
dist\backbone_state_tracker_v0.8.11_20260612_release_manifest.txt
dist\backbone_state_tracker_v0.8.11_20260612_verify_release_package.ps1
dist\CURRENT_RELEASE.txt
dist\latest\

29. 반입 전 확인사항

  • ZIP 파일명에 의도한 버전이 포함되어 있는지 확인합니다.
  • dist/latest/ 또는 dist/CURRENT_RELEASE.txt가 현재 반입할 버전을 가리키는지 확인합니다.
  • ZIP 내부에 PACKAGE_INFO.txt가 있는지 확인합니다.
  • ZIP 내부 docs/RELEASE_CHECKLIST.md/html에서 반입 검증 순서를 확인합니다.
  • ZIP과 같은 이름의 .sha256.txt 파일이 dist/에 있는지 확인합니다.
  • 반입 후 Get-FileHash -Algorithm SHA256 결과가 .sha256.txt 또는 release_manifest.txt와 같은지 확인합니다.
  • python .\tools\verify_release_package.py .\dist\<package>.zip --require-manifest 검증이 성공하는지 확인합니다.
  • 소스 폴더가 없는 환경에서는 powershell -ExecutionPolicy Bypass -File .\<version>_verify_release_package.ps1 -Package .\<package>.zip -RequireManifest 검증이 성공하는지 확인합니다.
  • 검증 중 version mismatch 또는 date mismatch가 나오면 ZIP, sidecar, manifest가 같은 버전 세트인지 다시 확인합니다.
  • 검증 중 package mismatch, package size mismatch, package SHA256 mismatch가 나오면 sidecar 또는 manifest의 해당 패키지 레코드가 ZIP과 맞는지 다시 확인합니다.
  • 검증 중 Unsafe ZIP entry found 또는 Unexpected ZIP root entry found가 나오면 ZIP 내부 경로가 backbone_state_tracker/ 루트와 안전한 상대 경로 기준을 지키는지 다시 확인합니다.
  • docs/ 폴더에 사용자 가이드, 명령어 가이드, 개발자 가이드, 버전 변경내역 문서가 Markdown/HTML 모두 있는지 확인합니다.
  • 소스 ZIP에 .git, outputs/, dist/, config/devices.yaml이 포함되지 않았는지 확인합니다.
  • Windows EXE ZIP에 BackboneStateTracker.exe가 포함되어 있는지 확인합니다.
  • 장비 IP, 계정, 원본 출력 등 내부 정보가 배포 파일에 포함되지 않았는지 확인합니다.
