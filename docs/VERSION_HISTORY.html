Backbone State Tracker 버전별 변경내역

문서 버전: v0.8.27
작성일: 2026-06-12
대상: 운영자, 인수자, 초급 유지보수 담당자

1. 최신 버전

v0.8.27 - 2026-06-12

  • 수집, 비교, 샘플 검증이 진행 중일 때 설정 점검을 차단하도록 했습니다.
  • 진행 중에는 설정 점검과 스냅샷 목록 새로고침 버튼을 비활성화합니다.
  • busy 상태 버튼 잠금과 설정 점검 차단에 대한 GUI 회귀 테스트를 추가했습니다.

2. 이전 주요 변경

버전날짜주요 내용
v0.8.262026-06-12장비 설정 화면을 스크롤 가능하게 만들고 대상 장비 입력 요약을 추가했습니다.
v0.8.252026-06-12대상 장비 영역에 장비 추가 버튼을 추가하고 3대 이상 YAML 불러오기를 지원했습니다.
v0.8.242026-06-12HTML 비교 리포트에서 변경이 있는 장비/명령으로 바로 이동하는 변경 항목 바로가기 버튼을 추가했습니다.
v0.8.232026-06-12HTML 리포트에서 변경없음 요약 카드 묶음도 기본 접힘 상태로 변경했습니다.
v0.8.222026-06-12HTML 리포트 상단 메타에서 샘플 스냅샷을 샘플: 접두어로 표시했습니다.
v0.8.212026-06-12GUI 상단 런타임 요약에서 샘플 스냅샷을 샘플: 접두어로 표시했습니다.
v0.8.202026-06-12샘플 검증 스냅샷이 실제 작업 전 기준으로 선택되지 않도록 제외했습니다.
v0.8.192026-06-12HTML 비교 리포트 등급 필터 전환성과 한글 폰트 가독성을 개선했습니다.
v0.8.182026-06-12수집 기능을 장비 설정에 통합하고 마법사/별도 수집 메뉴를 제거했습니다.
v0.8.172026-06-12앱 시작 화면을 장비 설정으로 재배치했습니다.
v0.8.162026-06-12HTML 요약 카드와 GUI 비교 지표 영역을 개선했습니다.
v0.8.152026-06-12대시보드 제거와 작업 로그 자동 이동을 추가했습니다.
v0.8.142026-06-12checksum sidecar Date stamp 검증을 추가했습니다.
v0.8.82026-06-12릴리스 반입 체크리스트를 필수 문서로 추가했습니다.
v0.8.7 이하2026-06-11 이전스냅샷 비교, redaction, 공유 ZIP, 샘플 검증, GUI 상세 비교 기능을 단계적으로 추가했습니다.

v0.8.26 - 2026-06-12

  • 장비 설정 화면을 세로 스크롤 가능하게 바꿔 대상 장비 행이 늘어나도 하단 수집 컨트롤에 접근할 수 있게 했습니다.
  • 대상 장비 영역에 사용 N대 / 입력 N대 / 행 N개 요약을 추가했습니다.
  • 스크롤 설정 화면과 대상 장비 요약 갱신에 대한 GUI 회귀 테스트를 추가했습니다.

v0.8.25 - 2026-06-12

  • 장비 설정의 대상 장비 영역에 장비 추가 버튼을 추가했습니다.
  • 기본 2개 장비 행은 유지하면서 필요 시 추가 장비를 같은 화면에서 입력할 수 있습니다.
  • 장비 YAML에 3대 이상이 들어 있어도 필요한 만큼 행을 자동으로 만들고, 짧은 목록을 다시 불러오면 남는 행을 빈 기본값으로 초기화합니다.
  • 동적 장비 행에 대한 GUI 회귀 테스트를 추가했습니다.

v0.8.24 - 2026-06-12

  • HTML 비교 리포트 상단에 변경 항목 바로가기 버튼 영역을 추가했습니다.
  • 긴급, 주의, 정보처럼 변경이 있는 장비/명령만 버튼으로 표시하고, 누르면 해당 명령별 상세 블록으로 바로 이동합니다.
  • 변경 항목 바로가기와 목적지 강조 동작에 대한 회귀 테스트를 추가했습니다.

v0.8.23 - 2026-06-12

  • HTML 비교 리포트에서 변경없음 요약 카드 묶음도 기본 접힘 상태로 변경했습니다.
  • 변경없음 필터 또는 상세 링크를 사용할 때 접힌 요약/상세 영역이 자동으로 열리도록 했습니다.
  • HTML 리포트 변경없음 접힘 동작에 대한 회귀 테스트를 추가했습니다.

v0.8.22 - 2026-06-12

  • HTML 비교 리포트 상단의 기준/비교 메타 정보에 샘플 스냅샷이 들어가면 샘플: 접두어를 붙였습니다.
  • 공유용 샘플 검증 리포트가 실제 작업 증적과 섞여 보이지 않도록 구분성을 높였습니다.
  • HTML 리포트 샘플 표시명에 대한 회귀 테스트를 추가했습니다.

v0.8.21 - 2026-06-12

  • GUI 상단 런타임 요약의 기준/비교 대상에 샘플 스냅샷이 선택되면 샘플: 접두어를 붙여 실제 작업 기준과 구분했습니다.
  • 샘플 스냅샷 표시명에 대한 GUI 회귀 테스트를 추가했습니다.

v0.8.20 - 2026-06-12

  • 샘플 검증 스냅샷이 실제 작업 전 기준 스냅샷으로 선택되지 않도록 제외했습니다.
  • 샘플만 존재하는 상태에서 첫 실제 수집을 시작하면 여전히 작업 전 기준으로 저장되도록 보장했습니다.
  • workflow 함수와 GUI 기본 수집 단계에 대한 회귀 테스트를 추가했습니다.

v0.8.19 - 2026-06-12

  • HTML 비교 리포트에서 등급 필터를 적용해도 요약 카드는 계속 보이도록 개선했습니다.
  • 요약 카드의 상세 보기 링크를 누르면 해당 상세 블록이 보이도록 필터를 자동 조정합니다.
  • HTML 리포트 기본 폰트 스택에 Malgun Gothic을 우선 적용했습니다.
  • HTML 등급 필터 동작을 검증하는 회귀 테스트를 추가했습니다.
